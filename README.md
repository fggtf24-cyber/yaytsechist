# Яйцечист

Чистит Windows от мусора, показывает, что занимает место на диске, и ускоряет отклик в играх. Один `.exe`, установка не нужна.

**[Скачать Яйцечист](https://github.com/fggtf24-cyber/yaytsechist/releases/latest/download/Yaytsechist.exe)** (Windows 10/11, 64 бита)

При запуске программа попросит права администратора: без них нельзя чистить системные папки и менять настройки. Файл не подписан сертификатом, поэтому Windows может показать предупреждение SmartScreen: нажми «Подробнее», затем «Выполнить в любом случае».

## Что умеет

- **Оптимизация для игр.** Свой план питания, таймер 0.5 мс, отключение Game DVR. Всё возвращается одной кнопкой.
- **Очистка диска.** Временные файлы, кэш обновлений, браузеров и лаунчеров, отчёты об ошибках, корзина, медиакэш Adobe (Premiere, After Effects, Media Encoder), остатки обновлений Windows.
- **Место на диске.** Схема из прямоугольников, папки с раскрытием по стрелке, самые большие файлы, разбивка по типам, поиск, отправка в корзину или удаление навсегда (в том числе клавишами Delete и Shift+Delete), выгрузка в CSV.
- **Очистка памяти.** Вручную, по порогу загрузки или по расписанию.
- **Удаление программ.** Список установленных программ с поиском. Сначала запускается собственный удалитель программы, потом Яйцечист находит остатки: папку установки, папки в AppData и ProgramData, ярлыки в «Пуске» и на рабочем столе, ключи реестра. Что удалять, выбираешь галочками. Папки уходят в корзину, ключи реестра перед удалением сохраняются в `%LOCALAPPDATA%\GameBoost\reg-backup`. У программ Adobe удаляются только папки их версии (например, `Adobe\After Effects\26.x`), а кнопка «Остатки Adobe», как Creative Cloud Cleaner Tool, находит папки и ярлыки версий Adobe, которых на компьютере уже нет. В меню Проводника у ярлыков и exe появляется пункт «Удалить через Яйцечист», который открывает программу сразу на нужной строке (в Windows 11 он лежит в «Показать дополнительные параметры»). Галочка в настройках делает так, что кнопка «Удалить» в «Параметрах» Windows открывает Яйцечист. Настоящая команда удаления хранится рядом в реестре и возвращается на место, когда галочку снимают или программу удаляют. Пока галочка стоит, не перемещай и не удаляй exe. В списке программ видно, когда каждую запускали в последний раз (по журналам Windows UserAssist и Prefetch), и есть сортировка «Давно не открывал».
- **Работа в фоне.** Значок в трее и запуск вместе с Windows включаются в настройках.
- **Автообновление.** При запуске программа проверяет новую версию на GitHub и предлагает обновиться. Скачанный файл сверяется по контрольной сумме.
- **Два языка.** Русский и английский, переключаются в настройках.

## Важно

- Часть настроек оптимизации меняет план питания, реестр и параметры загрузки Windows. Прежние значения сохраняются, и кнопка выключения возвращает их, но перезагрузка всё равно понадобится.
- Очистка диска удаляет файлы навсегда. Отправка в корзину есть только во вкладке «Место на диске».

## English

Yaytsechist cleans junk from Windows, shows what takes up disk space and improves game responsiveness. It is a single `.exe`, no installation needed. The interface is available in English: choose it in Settings. **[Download](https://github.com/fggtf24-cyber/yaytsechist/releases/latest/download/Yaytsechist.exe)**

## Сборка из исходников

Нужен Python 3.12 и зависимости:

```bash
pip install pywebview pystray pillow pyinstaller
```

Затем запусти `Сборка exe.bat`. Проверка логики: `python gameboost.py --selftest`.

Шрифты Inter Tight и IBM Plex Mono распространяются по лицензии SIL OFL, тексты лицензий лежат в папке `fonts`.
